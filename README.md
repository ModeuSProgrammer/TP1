Вариант: 20

Описание веток:

main - хранит в себе релизную версию после выполнения всех заданий, а также файлы .gitignore и readme.md;

task_1 - модуль реализован для того чтобы бы проанализировать таблицу по варианту и сохранить отчёт с дублированием в консоль.

task_2 - модуль основанный на прошлом задании, реализован для работы с счетными данными и их отобжражением в виде графика.

task_3 - модуль основанный на прошлом задании, увеличино количество разновидностей графика, а также выводятся категориальные данные.
